## 💡 How to Contribute

Contributions are not only code. Every kind of help counts:

| Contribution | Examples |
|--------------|----------|
| 🐛 Bug reports | Open an issue with reproduction steps, your FPC/Lazarus version and OS |
| 💻 Code | Bug fixes, new features, performance improvements |
| 🧪 Unit tests | Add coverage for units that are not tested yet |
| 📖 Documentation | Improve the READMEs, write tutorials, translate |
| 🧩 Examples | Add sample applications to the [`examples/`](examples) folder |
| 💬 Community | Help answer other users' questions |

The full workflow and guidelines are in **[CONTRIBUTING.md](CONTRIBUTING.md)**.
